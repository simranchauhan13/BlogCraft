\# BlogCraft 📝



A full-stack blogging platform built with React, Node.js, Express, Prisma and PostgreSQL.



\## Features



\- User authentication using JWT

\- User signup and signin

\- Create and publish blogs

\- Read all blogs

\- Protected blog routes

\- Prisma ORM with PostgreSQL

\- Type-safe validation using Zod



\## Tech Stack



\### Frontend

\- React.js

\- TypeScript

\- Tailwind CSS

\- React Router

\- Axios



\### Backend

\- Node.js

\- Express.js

\- TypeScript

\- Prisma ORM

\- PostgreSQL

\- JWT Authentication



\### Common Package

\- Shared validation schemas using Zod



\## Project Structure
BlogCraft
│
├── frontend
├── backend
└── common


## Setup

### Backend


cd backend
npm install


Create `.env` file:


DATABASE_URL=your_database_url
JWT_SECRET=your_secret


Run backend:


npm run dev


### Frontend


cd frontend
npm install
npm run dev
